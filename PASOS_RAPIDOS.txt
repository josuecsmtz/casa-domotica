CASA DOMOTICA - PASOS RAPIDOS

1) ESP32
   Carga:
   esp32/ESP32_Casa_Domotica_UART2_Raspberry.ino

2) UART
   ESP32 GPIO17 TX2 -> Raspberry GPIO15 RX / pin 10
   ESP32 GPIO16 RX2 <- Raspberry GPIO14 TX / pin 8
   GND                <-> GND / pin 6

3) Raspberry
   cd raspberry
   chmod +x install.sh
   sudo ./install.sh
   sudo reboot

4) Conectate:
   WiFi: Casa-Domotica
   Clave: CasaDomotica2026

5) Abre:
   http://10.42.0.1:8080

6) SSH:
   ssh pytito-4@10.42.0.1

7) Diagnostico:
   cd /opt/casa-domotica
   ./status.sh

IMPORTANTE:
La instalacion usa GPIO14/GPIO15 para la ESP32.
La consola serial de Linux por esos pines queda desactivada.
